## Installer display correction

The Progress page no longer assigns simultaneous large fixed minimum heights to both the checklist and the expanded technical console. The completion/failure status is placed above the technical details section, and expanding the console temporarily reduces the checklist height so the wizard button row is never used as content space.

## Preserved architecture

0.1.0 retains the managed AppImage registry, exact-path repair/uninstall/purge, safe internal ZIP-link materialization, no-sudo/no-dnf AppImage build policy, opt-in GitHub editor catalogue with terminal/environment hard-disable, and pre-GUI silent document dispatch.
