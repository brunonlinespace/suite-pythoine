# Suite Pythoine
Build your own toolbox.

This is a one-stop shop to manage any of my modular editors and launch their respective file types in an integrated fashion. It keeps both portable version and AppImage versions of the editors you may wish to use. With this hub:
- You can drag and drop any of my *.zip files into it, and an installation wizard will prompt you if you want to build the AppImage using the build script inside the module you just loaded.
- You can then choose which version you prefer to use: portable, AppImage, or automatic.
- You can open any file (.py, .sh, .txt, .md, .html, .css, .etc) type as long as the module is loaded.
- You can also choose to keep portable version or uninstall AppImage, or keep both, or keep none with a purge function.
